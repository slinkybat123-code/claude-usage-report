About Limit

Limit is a usage tracker for Claude Code and the other AI tools you pay for. It shows what your chats cost, how close you are to your plan limits, and what each AI adds to your bill, on any phone or computer.

Who it's for

  • People who use Claude Code most days, on a Pro or Max plan or with API billing, and want to know where their usage goes.
  • Anyone who also pays for the OpenAI API, OpenRouter or the Claude API and would like one page for all of it.
  • Friends who like to compare. Sharing is off until both of you agree.

How it gets your figures

Claude Code keeps a record of every chat on your computer, in the .claude folder in your home folder. The Limit app reads those files, works out totals and what they would cost at API prices, and sends the results to your account. It reads only Claude Code's own records, not your project files, and it never asks for your Claude password.

If you choose, the installer also adds a small reporter to Claude Code. It writes down the plan-limit readings Claude Code already receives (the figures /usage shows), so Limit can show them too. It never changes or holds up a request.

Other AIs are added on the All your AIs page, with a key from that provider that can read usage.

The dollar figures for Claude Code are API list prices. On a subscription that's what the same usage would cost through the API, not what you pay.

How it's paid for

Limit is free. Ads on the public pages, like this one and the guides, pay for it. The pages you see after signing in (your dashboard, All your AIs, Friends and Computers) have no ads at all. If Limit saves you money, you can also support it with the link at the bottom of every page.

Open source

The code for the website and the app is on GitHub, so you can see exactly what the app reads and sends.
