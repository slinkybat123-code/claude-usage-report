Contact

The quickest way to reach the people behind Limit is GitHub.

Questions, problems and ideas

Open an issue at Limit's GitHub issues page. You need a free GitHub account. Say what you saw, whether it's on Windows, Mac or a phone, and what you expected to happen.

Issues are public. Never paste an API key, a link code or anything else private into one.

Your data

You can delete your account and everything stored with it yourself: sign in, open Computers and choose Delete my account. To stop one computer from sending, unlink it on the same page. If something doesn't work, open an issue without personal details and we'll reply there.

Security problems

Please don't post the details publicly. Open an issue that just says you've found a security problem, and we'll arrange a private way to talk.
