What it does

What each chat costs

Limit reads the files Claude Code already keeps and shows what every chat, day and model would cost at API prices, with the tokens behind it.

Your plan limits

The 5-hour and weekly limits that /usage shows, how fast you're using them, and when each one resets.

All your AIs

OpenAI, OpenRouter, the Claude API, Codex CLI and Gemini CLI next to Claude Code, so one page shows the whole bill.

Friends, if you like

Invite a friend by email. Once you both agree, you see each other's totals and limits. Never chat titles or folders.

How it works

  1. Sign in with Google. Your figures live in your account, so the site works on any device.
  2. Install the small app on the computer where you use Claude Code. It sends your figures to your account and nothing else, and it never asks for a Claude password.
  3. Open the site anywhere. Your phone shows the same dashboard, even when your computer is off or asleep.
